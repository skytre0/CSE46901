# Intro to Robotics (CSE46901)

This repository contains assignments and projects for the **CSE46901: Intro to Robotics** course. The projects are implemented using Unity and focus on robotic exploration, multi-agent systems, and simulation.

## Repository Structure

The projects are organized into separate folders, each containing:
- **`src/`**: Unity `.unitypackage` files containing the implementation.
- **`docs/`**: Project reports (PDF) and reference materials from TAs.
- **`media/`**: Demo videos (MP4) and other multimedia assets.
- **`images/`**: Important screenshots, diagrams, and visualizations.
